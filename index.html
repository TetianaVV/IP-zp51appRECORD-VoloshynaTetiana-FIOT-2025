Тема: DollArt — інтернет-магазин авторських ляльок ручної роботи.

Мета: Створити макет та головну сторінку веб-застосунку з HTML, таблицями, формами, списками та зображеннями.

Опис предметного середовища

DollArt — це веб-платформа для демонстрації та продажу текстильних ляльок ручної роботи. Користувач переглядає каталог, обирає ляльку, додає її в кошик та оформлює замовлення. Майстриня отримує контактні дані і виготовляє/надсилає замовлення. Адміністратор (майстриня) може додавати нові ляльки, редагувати опис, змінювати статус товарів.

Теорія.

Тег <table> визначає HTML таблицю. Кожен рядок таблиці визначається тегом <tr>. Кожен заголовок таблиці визначається тегом <th>. Кожна чарунка з даними таблиці визначається тегом <td>. За замовчуванням текст в елементах <th> виділений жирним шрифтом і відцентрований. За замовчуванням текст в елементах <td> є звичайним і вирівняним за лівим краєм.

HTML-код зображення

                    <img src="images/лялька2.jpg" alt="Лялька ручної роботи в помаранчевому платті">
                    <img src="images/лялька1.jpg" alt="Лялька ручної роботи в блакитному платті">
                    <img src="images/заєць1.jpg" alt="Заєць ручної роботи в блакитному костюмі">
                    <img src="images/заєць2.jpg" alt="Заєць ручної роботи в лавандовому костюмі">

Cкріншот зображення.

Теорія.

В HTML зображення визначаються за допомогою тега <img>. Тег <img> пустий, містить лише атрибути і не має закриваючого тега. Атрибут src вказує URL (вебадресу) зображення. Атрибут alt надає альтернативний текст для зображення, якщо користувач з якоїсь причини не може його переглянути: через повільне підключення до Інтернету, помилки в атрибуті src або якщо користувач використовує програму читання з екрана (скрінрідер). Значення атрибута alt має описувати зображення, тобто те, що на ньому зображено. Можна використовувати атрибути width та height. Атрибути width та height завжди визначають ширину і висоту зображення в пікселях.

Cкріншот форми.

Теорія.

HTML елемент <form> визначає форму, яка використовується для збору користувацького вводу. Елемент <input> є найбільш важливим елементом форми. Елемент <input> може відображатися кількома способами, в залежності від атрибута type. <input type="text"> Визначає однорядкове поле вводу текста. <input type="radio"> Визначає перемикач (для выбору одного з кількох варіантів). <input type="submit"> Визначає кнопку відправки (для відправки форми). Атрибут action визначає дію, яку буде виконано при надсиланні форми. Зазвичай дані форми відправляються на вебсторінку на сервері, коли користувач натискає кнопку надсилання (submit). Атрибут target вказує, чи буде надісланий результат відкриватися в новій вкладці браузера, у фреймі або в поточному вікні. За замовчуванням значення '_self' означає, що форма буде відправлена в поточному вікні. Щоб зробити результат форми відкритим в новій вкладці браузера, використовуйте значення '_blank'. Іншими допустимими значеннями є '_parent', '_top' або name, яке представляє ім’я iframe. Атрибут method вказує метод HTTP (GET або POST), який буде використовуватись при надсиланні даних форми Кожне поле вводу повинно мати атрибут name для надсилання. Якщо атрибут name опущений, дані його поля вводу не будуть відправлені взагалі. Елемент <fieldset> використовується для групування пов’язаних даних у формі. Елемент <legend> визначає заголовок для елемента <fieldset>.

Cкріншот списку.

Теорія.

Невпорядкований (ненумерований) список починається з тега <ul>. Кожний елемент списку починається з тега <li>. CSS властивість list-style-type використовується для визначення стиля маркера елемента списку: disc: Встановлює маркер елемента списка як маленьке чорне коло (за замовчуванням); circle: Встановлює маркер елемента списка у вигляді маленького пустого кола; square: Встановлює маркер елемента списка у вигляді квадрата; none: Елементи списка не будуть відмічені (маркери відсутні). Впорядкований (нумерований) список починається з тега <ol>. Кожний елемент списку починається з тега <li>. Атрибут type тега <ol> визначає тип маркера елемента списка: type="1": Елементи списка будуть пронумеровані цифрами (за замовчуванням); type="A": Елементи списка будуть пронумеровані заглавними літерами; type="a": Елементи списка будуть пронумеровані рядковими літерами; type="I": Елементи списка будуть пронумеровані великими римськими цифрами; type="i": Елементи списка будуть пронумеровані маленькими римськими цифрами.

Лабораторна робота №2: Тема та Мета

Тема: Каскадні таблиці стилів. Селектори. Ідентифікатори. Стилі оформлення тексту.

Мета: Вивчити методи підключення CSS до HTML-документа, опанувати роботу з селекторами та навчитися стилізувати текстові елементи.

Способи підключення стилів

  • Зовнішній (External): Через тег <link rel="stylesheet" href="style.css"> у head.
  • Внутрішній (Internal): Всередині тега <style> у head.
  • Вбудований (Inline): Через атрибут style="..." безпосередньо в тегу.

Селектор тегу

Використовується для застосування стилів до всіх елементів певного типу.

p { color: grey; }

Селектор класу

Дозволяє стилізувати групу елементів. В HTML пишеться class="name", в CSS через крапку.

.highlight { background: yellow; }

Селектор ідентифікатора

Використовується для унікального елемента на сторінці. В CSS через решітку.

#main-header { font-size: 24px; }

Каскадування та Спадкування

Каскадування — це механізм вирішення конфліктів, коли до одного елемента застосовуються різні правила (пріоритет: inline > id > class > tag).

Спадкування — це передача властивостей (наприклад, font-family) від батьківського елемента до дочірніх.

                    // Завдання 1
// Функція для виконання Завдання 1
function task1() {
    //  Отримуємо значення від користувача
    const input = prompt("Введіть будь-яке число:");
    
    // Перетворюємо рядок у число
    const value = Number(input);
    
    //  Виводимо значення в консоль за допомогою шаблонного рядка
    console.log(`Користувач ввів значення: ${input}`);
           
    //  Перевірка знаку числа та виведення результату через alert()
    if (value > 0) {
        alert(`Число ${value} додатне`);
    } else if (value < 0) {
        alert(`Число ${value} від’ємне`);
    } else {
        alert(`Число ${value} дорівнює нулю`);
    }
}

// Запуск завдання
task1();

    }

    // Виводимо повідомлення

    alert(`Число ${number} - ${result}`);

    //  Виводимо результат у консоль

}

// Завдання 3
// Функція для виконання Завдання 3
function task3() {
    // Ініціалізуємо користувачів та їхні паролі
    const adminLogin = "Admin";
    const adminPassword = "1234"; 
    
    const userLogin = "User";
    const userPassword = "9876";

    // Запитуємо логін у користувача
    const loginInput = prompt("Введіть логін:");

    let statusMessage = "";

    // Перевірка логіна
    if (loginInput === null) {
        // Якщо натиснули Cancel або нічого не ввели
        statusMessage = "Cancelled";
        alert(statusMessage);
    } 
    else if (loginInput === adminLogin) {
        // Якщо ввели "Admin" - запитуємо пароль
        const passwordInput = prompt("Введіть пароль для Admin:");

        if (passwordInput === null) {
            statusMessage = "Cancelled";
        } else if (passwordInput === adminPassword) {
            statusMessage = "Hello, Admin";
        } else {
            statusMessage = "I don't know you";
        }
        alert(statusMessage);
    } 
    else if (loginInput === userLogin) {
        // Якщо ввели "User" - запитуємо пароль
        const passwordInput = prompt("Введіть пароль для User:");

        if (passwordInput === null) {
            statusMessage = "Cancelled";
        } else if (passwordInput === userPassword) {
            statusMessage = "Hello, User";
        } else {
            statusMessage = "I don't know you";
        }
        alert(statusMessage);
    }

function filterArray(numbers, value) {
    const filteredNumbers = []; // Новий масив для результатів

    // Цикл for для послідовного перебору всіх елементів масиву
    for (let i = 0; i < numbers.length; i++) {
        // Якщо елемент більший за вказане значення, додаємо його в новий масив
        if (numbers[i] > value) {

}

// Функція для створення та заповнення масиву А випадковими числами
function createArrayA(size) {
    const arr = [];
    for (let i = 0; i < size; i++) {
        // Заповнюємо випадковими числами від 1 до 20
        arr.push(Math.floor(Math.random() * 20) + 1);
    }
    return arr;
}

// Функція для побудови масиву B за формулою b_i = max * a_i
function generateArrayB(arrayA) {
    // Шукаємо максимальний елемент за допомогою вбудованого методу Math.max
    const max = Math.max(...arrayA);
    console.log(`Максимальний елемент масиву A (max): ${max}`);

    // Обчислюємо елементи масиву B
    const arrayB = [];
    for (let i = 0; i < arrayA.length; i++) {
        arrayB.push(max * arrayA[i]);
    }
    return arrayB;
}

// Функція сортування масиву за зменшенням методом ВСТАВКИ
function insertionSortDescending(arr) {
    // Робимо копію масиву, щоб не змінювати оригінальний
    const sortedArr = [...arr]; 
    
    for (let i = 1; i < sortedArr.length; i++) {
        let key = sortedArr[i];
        let j = i - 1;

        // Оскільки сортуємо за зменшенням, рухаємо елементи, які менші за key
        while (j >= 0 && sortedArr[j] < key) {
            sortedArr[j + 1] = sortedArr[j];
            j = j - 1;
        }
        sortedArr[j + 1] = key;
    }
    return sortedArr;
}

// Оголошуємо клас Client з приватними властивостями
class Client {
    // Приватні властивості обов'язково оголошуються на початку класу через #
    #login;
    #email;

    // Конструктор класу для ініціалізації початкових значень

        this.#login = login;
        this.#email = email;

    get login() {
        return this.#login;
    }

    // Сеттер для зміни приватного логіну

        if (newLogin.trim() === "") {
            console.log("Помилка: Логін не може бути порожнім рядком!");
            return;
        }
        this.#login = newLogin;
    }

    // Геттер для отримання приватного емейлу
    get email() {
        return this.#email;
    }

    // Сеттер для зміни приватного емейлу (з базовою перевіркою на символ @)
    set email(newEmail) {
        if (!newEmail.includes("@")) {
            console.log(`Помилка: Рядок "${newEmail}" не є коректним емейлом!`);
            return;
        }
        this.#email = newEmail;
    }
}

    { id: "001", likes: 2, tags: ["html", "css"] },
    { id: "002", likes: 17, tags: ["html", "js", "nodejs"] },
    { id: "003", likes: 8, tags: ["css", "react"] },
    { id: "004", likes: 0, tags: ["js", "nodejs", "react"] },
];

// Стрілочна функція для підрахунку кількості тегів
const countTags = (tweetsArray) => {
    // Використовуємо .reduce() для акумуляції результату в один об'єкт
    return tweetsArray.reduce((acc, tweet) => {
        // Деструктуризуємо властивість tags з об'єкта твіта
        const { tags } = tweet;

        // Перебираємо масив тегів конкретного твіта
        tags.forEach(tag => {
            // Якщо такий тег вже є в об'єкті acc, збільшуємо його лічильник на 1,
            // якщо немає — створюємо із початковим значенням 1
            acc[tag] = acc[tag] ? acc[tag] + 1 : 1;
        });

        return acc; // Повертаємо оновлений акумулятор на наступну ітерацію
    }, {}); // Початкове значення акумулятора — порожній об'єкт {}
};

// ЛАБОРАТОРНА РОБОТА №5 — ЗАВДАННЯ 2 (ВАРІАНТ 7)

class Calculator {
    constructor() {
        this.result = 0; // Поточне значення обчислень
    }

    // Встановлює початкове значення
    number(value) {
        this.result = value;
        return this; // Повертаємо сам об'єкт (this) для забезпечення ланцюжка
    }

    // Операція додавання
    add(value) {
        this.result += value;
        return this;
    }

    // Операція віднімання
    subtract(value) {
        this.result -= value;
        return this;
    }

    // Операція множення
    multiply(value) {
        this.result *= value;
        return this;
    }

    // Операція ділення з перевіркою на нуль
    divide(value) {
        if (value === 0) {
            console.error("Помилка: Ділення на нуль неможливе!");
            alert("Критична помилка: Ділення на нуль перервало ланцюжок!");
            return this;
        }
        this.result /= value;
        return this;
    }

    // Повертає фінальний результат усіх операцій
    getResult() {
        return this.result;
    }
}

// Головна функція для запуску та взаємодії з користувачем
function runDynamicCalculator() {
    console.log("СТАРТ: ЗАВДАННЯ 2, ВАРІАНТ 7 (КАЛЬКУЛЯТОР)");

    // Запитуємо стартове число
    const startInput = prompt("Калькулятор з ланцюжковим викликом методів.\nВведіть початкове число:");
   
    // Послідовно запитуємо числа для кожної математичної операції
    const addInput = prompt(`Поточний результат: ${startInput}\nСкільки ДОДАТИ?`);
    if (addInput === null) return;

    // Рахуємо проміжне значення суто для красивого відображення у наступному віконці
    const currentAfterAdd = Number(startInput) + Number(addInput);
    const subInput = prompt(`Поточний результат: ${currentAfterAdd}\nСкільки ВІДНЯТИ?`);
    if (subInput === null) return;

    const currentAfterSub = currentAfterAdd - Number(subInput);
    const mulInput = prompt(`Поточний результат: ${currentAfterSub}\nНа скільки ПОМНОЖИТИ?`);
    if (mulInput === null) return;

    const currentAfterMul = currentAfterSub * Number(mulInput);
    const divInput = prompt(`Поточний результат: ${currentAfterMul}\nНа скільки ПОДІЛИТИ?`);
    if (divInput === null) return;

    // Ініціалізуємо клас калькулятора
    const calc = new Calculator();

    // Запускаємо фірмовий ланцюжковий виклик (Method Chaining)
    const finalResult = calc
        .number(Number(startInput))
        .add(Number(addInput))
        .subtract(Number(subInput))
        .multiply(Number(mulInput))
        .divide(Number(divInput))
        .getResult();

    // Виводимо хід виконання в консоль
    console.log(`Користувацький вираз: ${startInput} + ${addInput} - ${subInput} * ${mulInput} / ${divInput}`);
    console.log("Результат обчислення об'єкта:", finalResult);

    // Виводимо фінальний звіт користувачу
    alert(
        `Обчислення успішно завершено!\n\n +
        Ваш математичний ланцюжок:\n +
        ${startInput} + ${addInput} - ${subInput} * ${mulInput} / ${divInput} = ${finalResult}\n\n +
        Повний лог операцій збережено в консолі.`
    );
}

// Автоматичний запуск програми при завантаженні сторінки
runDynamicCalculator();
